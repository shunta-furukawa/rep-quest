# REP QUEST

その1回が、冒険になる。iPhone向けの運動連動RPG / PWA。

## 開発

Node.js 22+、Python 3（ローカルサーバー用）。3D表示にThree.jsを使用します。

```sh
npm ci
npm test
npm run build
npm run dev
```

## 遊び方

- 腕立て：3秒の準備後、大きなカウント面へのタッチで計測。700ms以内の重複タッチを無視。
- スクワット：ユーザー操作でDeviceMotionEventの許可を要求。胸元で端末を持ち、加速度を重力方向へ投影して動作を検出。感度調整可能。モーション途絶時は一時停止。
- プランク：時間を計測。画面非表示時は停止し、再開時に準備時間を挟む。
- 1回10XP、プランク1秒2XP。レベルアップで称号・剣の名前が変化し、5セットで次のエリアへ進む。欠席によるペナルティなし。
- 回数と途中経過はlocalStorageへ保存。中断後の起動時は未確定セットを一度だけ確定。
- JSONバックアップと復元、サービスワーカーによるオフライン起動に対応。

## 制約

スクワット検出は実験的です。端末・速度・持ち方で誤検出や取りこぼしが生じます。合成波形のテストは実機精度の保証ではありません。フォームや運動効果の判定は行いません。

データは端末内のみ。Safariとホーム画面アプリで保存領域が異なる場合があります。移行前にバックアップしてください。クラウド同期はありません。

## Vercel

GitHubのこのリポジトリをImportし、FrameworkをOther、Buildを `npm run build`、Outputを `dist` に設定（vercel.jsonで指定済み）。シークレット不要。mainへのpushで自動デプロイするVercel Git連携を推奨。

iPhoneのセンサー計測はHTTPSで確認してください。Safari・ホーム画面PWAの両方で、許可、10回の実測、一時停止、画面ロック、オフライン再起動を確認します。

## v0.2: 冒険者とカレンダー

- 3スロット。名前（1〜16文字）と6色の髪色を設定し、後から変更可能。スロット間で進捗・日別XPは独立。
- `rep-quest:v1` の旧保存は `rep-quest:v2` のスロット1へ移行。元キーは変更しない。日時が分かる履歴だけ日別へ集計し、不明なXPは累計に残して説明する。
- 日別XPは端末のローカル日付で記録。日跨ぎのセットを日別に分割。途中保存にも日付を残し、再起動時に元の日付へ一度だけ確定。直近100件のセット履歴とは別に日別集計を保持する。
- カレンダーは月移動、今日の強調、日別内訳、月の合計、日付更新に対応。未来の記録は作らない。
- バックアップは3スロット一括。旧v1 JSONも復元可能。復元は全スロットの置き換え確認付き。別タブから変更された場合は古い画面からの保存を停止し、再読込を案内。
- Three.js 0.180.0: ボクセル冒険者、髪色、剣・盾、焚き火・木・石の門。待機・攻撃・防御・達成モーションと左右ドラッグ回転。モデルはプリミティブから構築した初版で、コンセプト画像そのものの3D変換ではない。
- 単一WebGLキャンバスを各画面へ移動。30fps上限、pixel ratio最大1.5、背景のInstancedMesh、非表示時の描画停止。WebGLが使えなくても計測・記録は継続。
- npm ci後にbuildがThree.jsをdist/vendorへ配置。CDN依存なし。更新したサービスワーカーは古い画面をすべて閉じた後に有効化。

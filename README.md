# REP QUEST

その1回が、冒険になる。iPhone向けの運動連動RPG / PWA。

## 開発

Node.js 22+、Python 3（ローカルサーバー用）。3D表示にThree.jsを使用します。

```sh
npm ci
npm test
npm run build
npm run dev
```

## 遊び方

- 腕立て：3秒の準備後、大きなカウント面へのタッチで計測。700ms以内の重複タッチを無視。
- スクワット：ユーザー操作でDeviceMotionEventの許可を要求。胸元で端末を持ち、加速度を重力方向へ投影して動作を検出。感度調整可能。モーション途絶時は一時停止。
- プランク：時間を計測。画面非表示時は停止し、再開時に準備時間を挟む。
- 1回10XP、プランク1秒2XP。職業XPの到達段階で称号・装備が変化し、5セットで次のエリアへ進む。欠席によるペナルティなし。
- 回数と途中経過はlocalStorageへ保存。中断後の起動時は未確定セットを一度だけ確定。
- JSONバックアップと復元、サービスワーカーによるオフライン起動に対応。

## 制約

スクワット検出は実験的です。端末・速度・持ち方で誤検出や取りこぼしが生じます。合成波形のテストは実機精度の保証ではありません。フォームや運動効果の判定は行いません。

データは端末内のみ。Safariとホーム画面アプリで保存領域が異なる場合があります。移行前にバックアップしてください。クラウド同期はありません。

## Vercel

GitHubのこのリポジトリをImportし、FrameworkをOther、Buildを `npm run build`、Outputを `dist` に設定（vercel.jsonで指定済み）。シークレット不要。mainへのpushで自動デプロイするVercel Git連携を推奨。

iPhoneのセンサー計測はHTTPSで確認してください。Safari・ホーム画面PWAの両方で、許可、10回の実測、一時停止、画面ロック、オフライン再起動を確認します。

## v0.2: 冒険者とカレンダー

- 3スロット。名前（1〜16文字）と6色の髪色を設定し、後から変更可能。スロット間で進捗・日別XPは独立。
- `rep-quest:v1` の旧保存は `rep-quest:v2` のスロット1へ移行。元キーは変更しない。日時が分かる履歴だけ日別へ集計し、不明なXPは累計に残して説明する。
- 日別XPは端末のローカル日付で記録。日跨ぎのセットを日別に分割。途中保存にも日付を残し、再起動時に元の日付へ一度だけ確定。直近100件のセット履歴とは別に日別集計を保持する。
- カレンダーは月移動、今日の強調、日別内訳、月の合計、日付更新に対応。未来の記録は作らない。
- バックアップは3スロット一括。旧v1 JSONも復元可能。復元は全スロットの置き換え確認付き。別タブから変更された場合は古い画面からの保存を停止し、再読込を案内。
- Three.js 0.180.0: ボクセル冒険者、髪色、剣・盾、焚き火・木・石の門。待機・攻撃・防御・達成モーションと左右ドラッグ回転。モデルはプリミティブから構築した初版で、コンセプト画像そのものの3D変換ではない。
- 単一WebGLキャンバスを各画面へ移動。30fps上限、pixel ratio最大1.5、背景のInstancedMesh、非表示時の描画停止。WebGLが使えなくても計測・記録は継続。
- npm ci後にbuildがThree.jsをdist/vendorへ配置。CDN依存なし。更新したサービスワーカーは古い画面をすべて閉じた後に有効化。

## v0.3: Guild art direction

コンセプトに合わせた紺・古金・シアンのテーマ、浮遊島のギルド背景、アウトラインSVGロゴ、運動ピクトグラム、伸縮可能な装飾枠を全画面に適用。PWA・Safari用アイコンも同じQの紋章へ更新。素材・生成プロンプトは `public/art/README.txt`。背景は約308KBのWebPで、ロゴとアイコンは外部フォント不要。すべてサービスワーカーでオフライン保存。

## v0.4: ピクセル冒険者と職業育成

- Three.js/WebGLを使わず、透過スプライトをCanvas 2Dでコマ送り。剣士・魔法使い・盗賊それぞれ5段階、待機・攻撃・達成モーション。各段階6姿勢のアトラス。魔法使いの待機は杖の連続性を優先して1姿勢を使用。
- 作成時に3職業の完成形を表示。成長図鑑では全15形態とモーションを自由に試せる。プレビューは保存されたXPへ影響しない。
- 全体XP・カレンダーと独立した職業XPとレベル。運動開始時の職業へXPを付与。転職しても各職業の進捗を保持。旧v2セーブは過去XPを剣士へ一度だけ引き継ぐ。
- 各職業の見た目は0/400/2400/9000/24000 XPで昇格。最初の10XPで勲章、以降も各段階で3つの勲章を表示。勲章はキャラ下の金の菱形、全身装備は段階ごとのスプライトに反映。最終段階以降も12000XPごとに熟練の星を加算。日数や連続ログインによる強制・減点はなし。
- 髪色は髪専用マスクへ合成。非表示時の描画停止・動きを減らす設定に対応。全アトラスと髪マスクはオフライン保存。

## v0.5: 職業ごとのレベルと撃破クエスト

- 各職業はLv.0から開始。100XPでLv.1、次は200XP。転職先のXPでレベルを表示し、元の職業へ戻ると続きから再開。
- ホームに全職業の累計XP、運動セット数、職業別レベル・XPを表示。既存のXP・日別記録は保持。
- 腕立て・スクワット1回で1体、プランク5秒で1体撃破。5体ごとに敵が切り替わり、職業別の攻撃エフェクトを再生。
- 記録の単位は引き続き実際の回数・秒数。プランクの5秒未満の端数も1秒2XPで保存し、撃破数は表示時に換算。
- 敵画像は画像生成による透過ピクセルスプライト（スライム・コウモリ・ゴーレム）を切り出して使用。

## v0.6: 全画面アプリレイアウト

- 端末の動的ビューポートとセーフエリアに合わせた固定シェル。下部ナビで冒険・育成・記録・設定を切り替える。
- 冒険はキャラ・職業レベル・3クエストを1画面へ。記録はカレンダーと累計・履歴の切り替え。
- 運動中はヘッダー・下部ナビを隠し、戦闘とカウンターを優先。やり方・感度パネルを開くと計測を一時停止する。
- 長い履歴、初回キャラ作成、拡大文字や横向きなどで収まらない内容は画面内スクロールでアクセスを保つ。

### アプリ内更新

上部の「更新確認」で手動確認できます。起動時・画面復帰時・表示中の5分ごとにも更新を確認し、新版が準備できると「更新する」に切り替わります。タップしたときだけ待機中のService Workerを有効化し、画面を再読み込みします。運動中は更新を適用せず、別タブで更新された場合もセットを中断しません。初めてこの機能を取り込む際だけ、旧PWAとSafariタブを閉じて開き直す必要があります。

## v0.7: モチベーション設計

量を積むだけでなく「前より強くなった」を毎回見せ、罰を使わずに翌日も開きたくなる仕組みを追加。ロジックは `public/motivation.js`。

- **ボス戦**：運動ごとにボスが1体。1回（プランクは1秒）で1ダメージ。初回HPは前回の回数+1（腕立て5・スクワット8・プランク20秒が下限）。倒せなかったぶんは残りHPとして次回へ持ち越す。撃破すると+50XP、超えたぶんはオーバーキルとして通常XPの半分を追加。次のボスは「これまでの最大HPと今回の回数の大きい方」+1回（プランクは+5秒）。v0.5の「1回で1体・5体ごとのWAVE」はこれに置き換えた。
- **自己ベスト・前回比**：1セットの最高記録を運動ごとに保持し、更新で+30XP。結果画面に前回比や自己ベストまでの残りを表示。運動中も「自己ベスト更新中！」を表示する。
- **休息ボーナス**：XPのない日が1日終わるごとに100XPずつ蓄積（上限300）。次の運動でXPを2倍にし、蓄積を使い切るまで続く。休みを減点ではなく次回の後押しにする。
- **今日の依頼**：日替わりで1種目。目標はその種目の自己ベストの1.2倍（最低10回・15回・30秒）で、その日の合計で達成すると+100XP。
- **戦利品・会心**：ボス撃破で素材、3%で星のかけら。運動中は1/8で「会心の一撃」の演出（XPは変わらない）。
- **章とレベル**：章はセット数ではなくボス撃破3体ごとに進む。地域は6つで、一巡後は「深層N」になり、同じ地域の繰り返しには戻らない。職業レベルに必要なXPは1レベルごとに100ずつ増えるが、500XPを上限にしてLv.5以降も上がりやすくした。
- ボーナスXPは職業XP・累計・日別の `bonus` に同じ値で記録し、バックアップの整合性検証に含める。既存セーブは初回表示時に履歴から自己ベストと最初のボスを作る。

## v0.8: モンスターの種類と図鑑

- 6つのエリアごとに、スライム・コウモリ・ゴーレムの属性違いが出現（森・風・氷霧・星屑・火焔・暁の6種 × 3種族 = 18種）。新しいボスは出現時点のエリアで決まり、持ち越し中のボスは出現したときの姿のまま残る。
- ボスが入れ替わるとき、10%で黄金のレア個体が出現。撃破で+100XPと星のかけら。次の相手がレアの場合は結果画面で予告する。
- 記録画面にモンスター図鑑（全21種）。未撃破はシルエットで表示し、初撃破で図鑑に登録。未撃破のボスには「NEW」を表示する。
- 画像生成は使わず、既存の3スプライトにCSSフィルターで色をつけて表示する。元画像の色味が種族ごとに違うため、フィルターは種族ごとに調整している。v0.7のセーブは、それまでの撃破数から森の3種を図鑑に登録して引き継ぐ。

## v0.9: 9種族・63種のモンスターと永続ボス種族

- 画像生成でマタンゴ（キノコ）、狼、骸骨兵、ウィスプ、ミミック、幼竜を追加。既存3種族と合わせ9種族、6地域の亜種54種＋黄金レア9種で図鑑63種。名前・ドロップはすべて一意。生成プロンプトと160px WebPへの加工手順は `public/sprites/README.txt`。
- `slot.bosses[mode].family` に出現時の種族を保存。familyのない旧ボスは旧3種の `count % 3` から一度だけ補完し、HP・属性・レア状態を維持。旧図鑑IDも継続して受け付ける。
- 次のボス撃破時に、到達地域の `REGION_POOLS` から既存のrngで種族を抽選。主な3種族は各重み8、その他6種族は各重み1（合計80%対20%）。全63種を収集できるよう、すべての地域に低確率の来訪種族を含める。
- 主な顔ぶれ：森＝slime/mushroom/bat、高原＝wolf/bat/golem、氷霧＝wisp/wolf/golem、星屑＝skeleton/mimic/wisp、火焔＝dragon/golem/skeleton、暁＝dragon/wisp/mimic。最初のボスは従来通りスライム。
- BONUS・TUNINGおよび休息への減点なしの方針は変更なし。既存のボーナス・成長・セーブ整合性の検証を維持。
- CSSによる全地域の色比較と、アプリ共通の図鑑描画を320/375/390px幅で確認できる `/monster-preview.html` を追加。実際のiPhoneでの描画は別途確認可能。
- 検証：既存32ケースを新しい種族数・出現規則に合わせて維持し、移行・持ち越し・地域抽選・図鑑ID・旧撃破数の補完5ケースを追加。

### セーブの削除

スロット画面の各セーブに「このセーブを削除」を追加。確認ダイアログで冒険者の名前を正確に入力したときだけ削除できる。削除は元に戻せないため、ダイアログ内でバックアップを案内する。ほかのスロットの記録には影響しない。削除したスロットを選択中だった場合は選択を解除する。

### 未到達の姿を伏せる

昇格の瞬間を報酬として強くするため、職業の姿は1段階先までしか見せない（`progression.js` の `formVisibility`）。

- 到達済みの段階と次の段階は、姿もモーションも見られる。次の段階には残りXPを表示する。
- その先の段階は、金の縁取りのシルエットと「？？？」だけを表示する。最終形は職業の目標文（例：光をまとう英雄へ）だけ見せる。
- キャラ作成画面と育成画面の職業カードは、完成形ではなくその職業の現在の姿（新規なら見習い）と目標文を表示する。v0.4の「作成時に3職業の完成形を表示」はこれに置き換えた。

## v0.10: スーパーマンと全身制覇

毎日こなすと全身を回せるよう、4種目にした。押す（腕立て伏せ）、しゃがむ（スクワット）、体幹（プランク）、体の後ろ側（スーパーマン）の4つ。

- スーパーマン：うつ伏せで両手両脚を浮かせてキープするタイマー種目。1秒2XP。背中・腰・お尻・太もも裏を鍛える。ボスHPの下限は15秒で、1体倒すごとに+5秒。
- 時間を計る種目は `MODES[mode].timer` で判定する（プランクとスーパーマン）。日付をまたぐ秒数の振り分け、5秒ごとの攻撃演出、守りのポーズはタイマー種目で共通。
- 全身制覇：同じ日に4種目すべてを1セット以上こなすと、1日1回だけ+100XP。ホームに進み具合（例：全身制覇 3/4）を表示し、今日こなした種目には✓を付ける。
- 既存セーブ：スーパーマンの自己ベストとボスがないデータも、読み込みと復元の検証を通す。初回表示時に自己ベスト0とボスを補う。
- ホームのクエストはスマホで2×2、幅の広い画面と横向きで4列。ボスの表示はHPを先頭にし、狭い画面で切れても持ち越し状態が見えるようにした。

## v0.11: 図鑑タブ、旅の現在地、物語

- **図鑑タブ**：下部ナビを5タブ（冒険・育成・図鑑・記録・設定）にし、モンスター図鑑を記録画面から独立させた。発見数、累計撃破数、レア撃破数を表示し、図鑑はエリアごとにまとめて並べる（現在地のエリアには「現在地」と表示）。
- **旅の現在地**：ホーム上部に「現在地 → 次の目的地」と灯標の進み具合（◆◇◇）を表示する。タップすると物語の画面が開く。記録画面にあった「冒険の道のり」はここへ移した。
- **物語**（`public/story.js`）：空に浮かぶアストラ群島で、消えかけた各地の「灯標」を灯していく旅。ボスを3体倒すとそのエリアの灯標が灯り、次のエリアへ進む。物語の画面には次の内容を表示する。
  - 現在地の紹介と灯標の進み具合
  - この地の魔物（図鑑で未発見なら「？？？」）
  - 次の目的地
  - これまでの旅（序章と、灯した灯標の記録）
  エリアを移ったときと、新しい冒険者を作ったときは、物語の画面を自動で開く。
- **エリアの背景**：`public/art/regions/<id>.webp` を置くと、ホームの背景と全画面の背景がそのエリアの絵になる。id は forest / highland / lake / ruins / volcano / summit。画像がないエリアは、これまでのギルドの絵が表示される（CSSで背景を重ねているため）。

- 6つの島を星脈の光の線でつないで表示する。灯標を灯した島は光り、線もつながる。現在地の島には冒険者のドット絵を立たせ、次の目的地へは点線の道を引く。

## v0.13: セット前の案内

- セットを始める前と一時停止中は、戦闘画面の上に案内パネルを出す。構えの絵、スマホの置き場所、フォームの要点を表示する。
- カウントダウン中は、大きな絵、残り秒数、1秒ごとの一言（例：「スマホを胸の下へ」→「手は肩幅に」→「あごでタッチ」）を出す。音がONのときは、一言をブラウザの読み上げでも伝える（iOSで読み上げを有効にするため、最初の一言は開始ボタンのタップ時に読む）。
- カウントダウンの長さは一言の数で決まる。立って行う種目（腕立て伏せ・スクワット）は3秒、床に伏せる種目（プランク・スーパーマン）は5秒。文言は `public/guide.js` にまとめている。
- 構えの絵：`public/art/guide/<mode>.webp`（mode は pushup / squat / plank / superman）を置くと表示される。ないあいだは、クエストのアイコンを大きく表示する。
- クエストのアイコン：`public/art/quest/<mode>.webp` を置くと、ホームのクエストボタンのアイコンがその絵に替わる。読み込みに成功したときだけ差し替えるので、ないあいだは従来のSVGが表示される。
- 2コマの動き：`public/art/guide/<mode>-2.webp`（動作の終わりの姿勢）を置くと、1枚目（始めの姿勢）と0.9秒ずつ交互に表示して動きを見せる。2枚目は1枚目と同じ大きさ・同じ構図で、人物の位置もそろえて描くこと。2枚目がない種目は1枚だけ表示する。動きを減らす設定のときは、1枚目だけを表示する。

## v0.14: 技の系譜

負荷を回数だけで上げると、1セットの回数が際限なく増え、鍛える中身が持久力に寄っていく。そこで、自重トレーニングの定番である「種目を難しくする」方向で負荷を上げる仕組みにした。定義は `public/techniques.js`。

| 種目 | 技の系譜（易 → 難、括弧は目標・威力） |

- **始め方**：どの種目も標準の技（太字）から始まる。それより易しい技には最初から戻れる。
- **習得**：目標の上限までこなしたセットが2回たまると、次の技を習得して+150XP。次のセットからはその技が選ばれた状態になる。習得した技には、開始前の画面の ‹ › でいつでも戻れる。
- **威力**：1回（キープ種目は1秒）あたりのボスへのダメージと経験値は、技の威力を掛けた値になる。難しい技は少ない回数でボスを倒せて、成長も速い。
- **ボスHPの上限**：腕立て20・スクワット25・プランク75秒・スーパーマン55秒。これ以上は回数ではなく技で負荷を上げる。上限を超えていた既存のボスは上限まで下げる。
- **自己ベストと前回比**：技ごとに記録する。今日の依頼の目標は、今の技の上限の約1.5倍（2セット分の目安）。
- **左右の技**：左右合計で数え、目標の上限の半分で「左右を入れ替え」を画面と音声で知らせる。
- **スクワットのセンサー**：技ごとに感度（ハーフ×0.75、スロー×0.6、スプリット・ブルガリアン×0.8など）と1回の最長時間（スロー・片脚系は9秒）を調整する。合成した波形でのテストのみで、実機での調整が必要。開始前の画面の「やり方・感度」も引き続き使える。
- **技の系譜の画面**：開始前の画面と育成画面から開ける。4種目の全技、目標、威力、習得状況、フォームを一覧できる。
- **既存セーブ**：標準の技から始まる。種目の自己ベストがすでに標準の技の上限以上なら、習得の証を1回分持った状態で始まる。
- **技の絵**：`public/art/guide/<技のid>.webp`（と `-2.webp`）を置くと、その技の構えとして表示する。ない技は、種目の標準の絵を表示する。

## v0.15: 共有カード

達成した瞬間を、画像つきでXなどに共有できる。画像は端末の中で作り、共有するまでどこにも送らない。ロジックは `public/share.js`。

- **結果画面**：特別な達成があったセットだけ「共有する：〇〇」ボタンを出す。1セットに複数あれば、技の習得 → 昇格 → 灯標 → レア撃破 → 全身制覇 → 自己ベストの順で最も大きいものを1つ選ぶ。
- **今週の冒険**：記録画面の「今週の冒険を共有」から、直近7日の運動日数・種目ごとの合計・ボス撃破数・XPをまとめたカードを作る。
- **カード**：1200×675のPNG。今いるエリアの背景、冒険者の今の姿、ロゴ、見出し、記録、日付、ハッシュタグ（#REPQUEST #筋トレ）を載せる。
- **共有の方法**：画像つきの共有に対応した端末（iPhoneのSafariなど）は、共有シートで画像と本文を渡す。対応していない場合は、Xの投稿画面を文章とURLだけで開き、画像は「画像を保存」から保存できる。
- **名前**：冒険者の名前は初期状態では載せない。共有画面のチェックで載せられ、設定は保存される（`shareName`）。
- **リンクのプレビュー**：OGP と Xカードを設定した。プレビュー画像は `public/og.jpg`（1200×630）。
